PROJECT DESCRIPTION
----------------------------------------

This application was created for elementary school students.

Its primary goal is to support children in:
- verbalizing concepts learned from educational texts
- improving sentence construction
- expanding vocabulary and language skills

The application encourages active learning through interaction,
stimulating both reasoning and oral expression.
